# 施設検索（施設登録）
## 管理項目
- ID : 施設ID ***必須***
- 属性 : 施設属性  
    マスター（病院属性）参照
- 法人名 : 法人名
- 施設名 : 施設名 ***必須***
- 施設カナ : 施設カナ
- TEL : 電話番号
- FAX : FAX番号
- メール : Eメールアドレス
- 追加連絡先
  - TEL : 電話番号
  - FAX : FAX番号
  - メール : Eメールアドレス
  - 名称 : 連絡先名称（部署等）
- 住所 : 住所
- 閉院日 : 閉院日
- FAX送信番号 : FAX送信先番号
- 非自動送信 : 受診報告送信一覧に表示しない
- 備考 : 備考

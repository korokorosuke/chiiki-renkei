# 問合せ登録
## 管理項目
- 問合せ日 : 問合せ日 ***必須***
- 患者 : 問合せ対象患者 ***必須***
- 問合せ施設 : 問合せ施設 ***必須***
    (施設登録)参照
- 問合せ者 : 問合せ者 ***必須***
    (施設医師登録)参照
- 連絡先 : 連絡先
- 期限 : 回答期限 ***必須***
    マスター（問い合わせ期限）参照
- 担当者 : 担当者 ***必須***
- 問合せ内容 : 内容 ***必須***
- 対応内容
  - 対応日時 : 対応日時 ***必須***
  - 対応者 : 対応者 ***必須***
  - 対応内容 : 対応内容 ***必須***
  - 対応完了 : 対応完了かどうか
